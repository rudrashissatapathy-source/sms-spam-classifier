# 📩 SMS Spam Classifier

An end-to-end Machine Learning web application that classifies SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP).

🔗 **Live Demo:** [sms-spam-classifier-5pq0.onrender.com](https://sms-spam-classifier-5pq0.onrender.com)

---

## 🚀 Features
- **Real-time classification:** Enter any text or SMS to predict whether it is spam.
- **NLP Preprocessing:** Text cleaning, tokenization (`punkt_tab`), stopword removal, and Porter stemming.
- **Interactive UI:** Built with Streamlit for a fast and clean user experience.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Streamlit, NLTK, Scikit-learn
- **Deployment:** Render
